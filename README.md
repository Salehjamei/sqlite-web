# سیستم مدیریت دیتابیس تحت وب (sqlite-web)

یک پنل مدیریت هوشمند و ریسپانسیو تحت وب برای دیتابیس‌های SQLite که با فریم‌ورک Blazor توسعه یافته است. این پروژه دارای یک پنل مدیریت پیشرفته برای کنترل دسترسی‌ها و مدیریت ادمین‌ها است.

## 🚀 ویژگی‌های کلیدی
* **مدیریت پیشرفته ادمین‌ها:** قابلیت ثبت، ویرایش، حذف و مدیریت سطوح دسترسی (سوپر ادمین و ادمین معمولی).
* **طراحی کاملاً ریسپانسیو:** بهینه‌سازی شده برای نمایش بی‌نقص در دسکتاپ و موبایل (همراه با منوهای بازشوی هوشمند).
* **امنیت بالا:** مجهز به سیستم احراز هویت، مکانیزم ابطال توکن، فریز حساب و مودال‌های هشدار تغییر دستی آدرس (URL Hijacking).
* **ثبت تردد و محاسبات کاری:** دارای فرمول‌های پیشرفته برای محاسبه ساعات کارکرد، اضافه‌کاری و ثبت دستی تردد پرسنل.

## 🛠 تکنولوژی‌های استفاده شده
* **Frontend & Backend:** .NET 9 / Blazor Web App (C#)
* **Database:** SQLite همراه با Entity Framework Core
* **UI Framework:** Bootstrap (راست‌چین شده و کاملاً پاسخگو)

## 💻 نحوه راه‌اندازی و اجرا

### پیش‌نیازها
* .NET SDK 9 یا بالاتر
* Visual Studio Enterprise 2026

### مراحل اجرا
۱. مخزن را کلون کنید:
```bash
git clone https://github.com/Salehjamei/sqlite-web.git
```

۲. وارد پوشه پروژه شوید:
```bash
cd sqlite-web
```

۳. ابزارها و وابستگی‌ها را بازیابی کنید:
```bash
dotnet restore
```

۴. پروژه را اجرا کنید:
```bash
dotnet run
```
